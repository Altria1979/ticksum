# 界面规范

参考图：`design/concept.png`，使用 imagegen 生成。图中文字和示例数据不是用户实际活动。

- 浅灰 #f7f8fa 背景、白色侧栏/内容区、#18202b 主文字、#13785b 主操作，细灰边框，8px 圆角。
- 210px 左侧栏，主内容 36px 间距，系统无衬线中文字体；标题 30px，正文 14px，指标 30px，说明 12px。
- 侧栏 TickSum、浏览概览、报告、设置；底部“数据保存在本机”。
- 概览标题“浏览概览”，说明“让浏览记录，成为可回顾的积累。”，主操作“生成报告”。
- 筛选栏：时间范围、搜索；高级网站与标签筛选、自定义时间为功能必要补充。
- 指标条：活动时长、浏览页面、内容快照；时间分布；浏览记录表；报告预览。
- 表格：复选、页面、网站、活动时长、内容；实际记录可选择、编辑标签与备注、查看正文。真实空状态不填充演示记录。
- 报告区：模板选择、可编辑 Markdown、保存/复制/导出；独立报告页列出历史报告。
- 设置页沿用相同控件；移动宽度侧栏改顶部导航，下方表格横向滚动，报告纵向排列。
- 示例仅存在于显式演示参数的 Web 预览，使用独立内存数据，不写入扩展数据库。
- 意图偏离：示例图报告虚构了理解/学习成果，实现改用可验证统计和标注的原文摘录；图中日期与数字均由真实数据生成。没有插画资源，品牌使用原生文字和简洁矢量时钟。

## 界面核验记录

已使用 `view_image` 对比生成参考图与浏览器截图。桌面按参考图实际尺寸 1505×1045 检查，另验证 1440×1000 与 390×844 窄屏。内置浏览器验证筛选→生成→保存→回看；Playwright 在独立浏览器验证复制、下载、响应式和真实扩展。

| 对比点 | 结果与有意调整 |
| --- | --- |
| 布局 | 保留侧栏、主标题、筛选、指标条、时间分布、表格/报告双列；窄屏改为纵排。 |
| 色彩 | 白色表面、浅灰背景、深色文字与绿色主操作一致。 |
| 字体 | 使用系统中文字体，区分标题、指标、标签和辅助说明；控件具有明确字号。 |
| 表格 | 页面与域名合并到同一单元格，为标签和正文详情留空间。 |
| 文案 | 保留导航/标题/操作；新增筛选、报告编辑和隐私说明来自已确认功能。 |
| 报告 | 改为可编辑 Markdown、增加标题与保存；保留来源与摘录边界，不采用概念图中推断出的学习成果。 |
| 数据 | 指标和柱图由合成演示片段计算，不能照抄概念图的示例数字。 |
