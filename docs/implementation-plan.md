# TickSum 首版

已确认：Chrome 扩展、React、自动计时、通用页面内容提取、筛选统计、报告编辑及复制导出。数据本地保存；AI 摘要、云同步和平台推送不属于本次首版。

## 交付与验收

- WXT / MV3 工程可类型检查、测试、构建并加载到 Chromium。
- 切换页面/窗口、闲置、锁屏、暂停和后台恢复不会重复计时；长时间无检查点的空档不补计。
- 正文仅在用户授予站点权限后采集，支持动态注册、已打开页面、SPA URL 变化、撤销权限。
- Readability 与有限的文档区域适配提取正文；输入框及编辑区域不采集，提取完整度明确标为部分/未知。
- 最近 X 小时、今天、自定义范围；搜索/网站/标签过滤；页面选择、标签备注、时间分布。
- 报告使用程序计算数字与带出处的原文摘录；模板不虚构学习成果。编辑、保存、复制、Markdown / CSV 导出。
- 初次安装为空数据，示例仅在独立预览模式显示且明确标识。
- 设置支持暂停、闲置阈值、排除网站、保留天数、正文授权/撤销、删除本地数据。

## 实现分工

- 主代理：共享契约、工程配置、React 界面、端到端验证、文档。
- 采集代理：后台状态机、站点授权注入、页面提取及对应测试。
- 数据代理：Dexie、统计、报告生成及对应测试。

## 验证

单测覆盖区间裁剪/重叠/跨日、分类、无快照和部分正文报告、URL 身份、后台重启与长空档、DOM 清理。端到端覆盖真实扩展导航记录、授权后采集、筛选、报告编辑保存导出、设置及独立预览响应式。人工系统锁屏/休眠未验证时必须记录限制。
